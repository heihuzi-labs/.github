## 黑胡子实验室 · Heihuzi Labs

黑胡子就是英文里的 Blackbeard，历史上最有名的海盗船长。我们做的开源工具都归在“船长”系列里：一个工具管一件事，每件都是先做给自己天天用，用顺手了再拿出来分享。

| 项目 | 做什么 | 状态 |
| --- | --- | --- |
| [船长派活 · Captain Agents](https://github.com/heihuzi-labs/captain-agents) | 让一个 AI 当负责人，把编码的活派给电脑上的 Codex、Grok、Cursor，在隔离里干活、在外面验收 | 在用 |
| [船长 K8s · Captain Kube](https://github.com/heihuzi-labs/captain-kube) | 给运维用的 Kubernetes 单集群管理台，看全局、查问题、改配置都在一个页面里 | 已发布 |
| [船长运维 · Captain Ops](https://github.com/heihuzi-labs/captain-ops) | 可以私有化部署的 AI 运维助手，在聊天里说一句，它去机器上排查，危险操作先审批 | 设计中 |
| [船长待办 · Captain Todo](https://github.com/heihuzi-labs/captain-todo) | 本地优先的桌面看板，按项目分列，拖一拖就排好，数据只存在自己电脑上 | 已发布 |

所有项目都用 MIT 许可证。欢迎提 issue，也欢迎直接拿去改。

---

Blackbeard, the most famous pirate captain in history, is 黑胡子 (heihuzi) in Chinese. Our open-source tools make up the Captain series: each one does one job, and each started as something we use every day before we shared it.

| Project | What it does | Status |
| --- | --- | --- |
| [Captain Agents](https://github.com/heihuzi-labs/captain-agents) | One AI leads and hands coding work to the Codex, Grok and Cursor CLIs on your Mac, sandboxed and verified outside | In use |
| [Captain Kube](https://github.com/heihuzi-labs/captain-kube) | A single-cluster Kubernetes console for the people who run it | Released |
| [Captain Ops](https://github.com/heihuzi-labs/captain-ops) | A self-hosted AI ops assistant: ask in chat, it investigates, risky actions wait for approval | Design |
| [Captain Todo](https://github.com/heihuzi-labs/captain-todo) | A local-first desktop kanban whose data stays on your own computer | Released |

Everything is MIT licensed. Issues and forks are welcome.
